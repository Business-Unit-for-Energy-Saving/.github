# Organization Overview

## 定位

`Business-Unit-for-Energy-Saving` 负责节能技术、能源管理与碳减排相关的长期业务和产品资产。

## 业务范围

- 企业和园区能源管理
- 能耗采集、监测和分析
- 能效诊断与节能改造
- 设备运行优化
- 节能量和减排效果评估
- 面向客户的节能咨询、软件和交付产品

## 非业务范围

- 通用工程平台和代码生成能力
- 集团战略、项目组合和治理制度
- 与节能业务无关的通用数据资产
- 未经确认的客户专属资料和生产环境细节

## 组织状态

当前状态：`Incubating`

进入 `Active` 前，应至少有明确负责人、持续维护的业务目标，以及一个真实维护的需求或产品仓库。
