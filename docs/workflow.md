# Workflow

## 新项目

1. 在 `requirements` 中记录业务目标、客户场景、负责人和预期产出。
2. 判断项目是否属于节能业务单元边界。
3. 通过 Issue 或 Project 明确优先级和依赖关系。
4. 需要代码、部署或数据资产时创建对应仓库。

## 跨 BU 协作

- 通用工程能力：协作 `Business-Unit-for-Platform`。
- 数据治理、知识库、RAG 或 BI：协作 `Business-Unit-for-Data-Intelligence`。
- 工作流、RPA 和 API 集成：协作 `Business-Unit-for-Automation`。
- 客户诊断、售前和交付方法：协作 `Business-Unit-for-Consulting`。
- 影响多个 BU 的决策：提交 `President-Office` 管理。

## 公开内容

组织 profile 和 Pages 只能发布已确认的公开信息。客户隐私、密钥、生产参数、内部合同和未确认路线图不得公开。
