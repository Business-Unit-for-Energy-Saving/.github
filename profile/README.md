# 节能业务单元 / Energy Saving

面向企业和园区的节能技术、能源管理与碳减排解决方案业务单元。

我们聚焦能源数据、能效诊断、节能改造、运行优化和减排效果评估，帮助客户把节能目标转化为可执行、可度量的业务成果。

## Boundary

- 业务需求、产品代码、专属数据、部署和运行状态归本业务单元。
- 通用工程底座归 `Business-Unit-for-Platform`。
- 跨 BU 数据、知识和自动化能力按总裁办治理规则协同。
- 不在公开仓库中保存客户隐私、生产配置或敏感凭据。
